# Cat (Interactive)

## โจทย์โดยย่อ

มี Permutation ลับ $P$ ขนาด $N$ โดยเราจะต้องเขียนฟังก์ชัน 

- `vector<int> select(int N)`
    - ในฟังก์ชันนี้ เราสามารถเรียกฟังก์ชัน `int ask(int i,int j)` ได้ โดยฟังก์ชันดังกล่าวจะคืนค่า $|P[i] - P[j]|$ และเราสามารถเรียกฟังก์ชันนี้ได้ไม่เกิน $Q$ ครั้ง
    - ฟังก์ชันนี้จะต้องคืนค่า `vector<int>` $A$ ที่มีขนาดอย่างน้อย $\lceil \frac{N}{2} \rceil$ ที่ทำให้เงื่อนไขต่อไปนี้เป็นจริง
        - $A[i] \neq A[j]$ สำหรับทุก $0 \leq i < j < |A|$
        - $|P[A[i]] - P[A[i+1]]| = 1$ สำหรับทุก ๆ $0 \leq i < |A| - 1$

หรือก็คือเราต้องเลือกค่าใน $P$ มาอย่างน้อย $\lceil \frac{N}{2} \rceil$ ค่า มาเรียงกันให้ทุก ๆ ค่าที่อยู่ติดกันมีผลต่างเท่ากับ $1$ พอดี

### ขอบเขตตัวแปร

- $1 \leq N \leq 10^5$

## Subtask 1, 2, 3 ($N \leq 100, Q = 10\ 000$)

ใน subtask นี้ เนื่องจาก $N^2 \leq Q$ เราเลยสามารถเรียก `ask(i, j)` สำหรับทุก ๆ คู่ `(i, j)` ที่เป็นไปได้ ทำให้เรารู้ค่า $|P[i] - P[j]|$ สำหรับทุกคู่ $0 \leq i, j < |A|$ ได้เลย

เพื่อความง่ายเราจะกำหนด $d[i][j]$ เท่ากับ $|P[i] - P[j]|$

**ข้อสังเกตที่ 1** : สำหรับ $i$ ที่ทำให้สำหรับแต่ละ $0 \leq j < N$ มีค่า $d[i][j]$ ที่ต่างกันทั้งหมด จะได้ว่า $P[i] = 1$ หรือ $P[i] = N$ เท่านั้น

ซึ่งเราสามารถสังเกตได้ไม่ยากว่า หาก $P[i]$ ไม่ใช่ $1$ หรือ $N$ จะทำให้มี $j_1, j_2$ ที่ $j_1 \neq j_2$ แต่ $d[i][j_1] = d[i][j_2]$ เสมอ

โดยหากเรารู้ $i$ ที่ $P[i] = 1$ หรือ $P[i] = N$ แล้วจะทำให้สามารถหาลำดับ $A$ ต่อได้โดยการใช้ลำดับ $A = [j_0, j_1, j_2, \ldots, j_{N-1}]$ ที่มีขนาด $N$ โดยที่ $d[i][j_k] = k$ สำหรับทุก ๆ $0 \leq k < N$

## Subtask 4 ($P[0] = 1, Q = 125\ 000$)

ใน subtask นี้สามารถนำไอเดียจาก subtask ที่แล้วมาทำต่อได้ เนื่องจากเรารู้แน่ ๆ ว่า $P[0] = 1$ เราเลยคำนวณเฉพาะ $d[0][j]$ สำหรับ $0 \leq j < N$ ก็พอ ซึ่งรวมแล้วจะถามทั้งหมดประมาณ $N$ รอบ 

## Subtask 5 ($Q = 200\ 000$)

ใน subtask นี้สามารถนำไอเดียจาก subtask ที่แล้วมาทำต่อได้ (อีกแล้ว) โดยสิ่งที่เราต้องหาเพิ่มคือ $i$ ที่ $P[i] = 1$ หรือ $P[i] = N$ 

**ข้อสังเกตที่ 2** : สำหรับ $i$ ใด ๆ หาก $m$ ทำให้ $d[i][m] \geq d[i][j]$ สำหรับทุก ๆ $0 \leq j < N$ แล้ว $P[m] = 1$ หรือ $P[m] = N$

ดังนั้นเราเลยสามารถจิ้ม $i$ มามั่ว ๆ ตัวนึงก่อนแล้วหา $m$ จากนั้น เราจึงนำ $m$ ไปคำนวณลำดับเหมือน subtask ที่แล้วได้เลย

รวมแล้วจะใช้การถามทั้งหมดประมาณ $2N$ รอบ

## Subtask 5 ($Q = 150\ 000$)

ทำแบบ Subtask 4 แต่เนื่องจากโจทย์ให้หาลำดับที่ยาวเพียง $\lceil \frac{N}{2} \rceil$ ตัว ในขั้นตอนการคำนวณลำดับ เราเลยวนเพียงแค่ $\lceil \frac{N}{2} \rceil$ รอบเท่านั้น 

รวมแล้วจะใช้การถามทั้งหมดประมาณ $\frac{3N}{2}$ รอบ

## Full Solution ($Q = 125\ 000$)

เริ่มต้น ให้เราจิ้ม $i$ มามั่ว ๆ แล้วคำนวณหา $d[i][j]$ สำหรับทุก ๆ $0 \leq j < N$

**ข้อสังเกตที่ 3 :** สำหรับแต่ละ $0 \leq k < N$ จะมี $j$ ที่ทำให้ $d[i][j] = k$ ไม่เกิน 2 ตัวเท่านั้น 

โดยเราสามารถมองเป็นกราฟ $y = |x - P[i]|$ ดังภาพ

![Abs Plot](/media/cat/abs.png)
*ตัวอย่างกราฟสำหรับ $P[i] = 4$ และ $N = 10$*

สังเกตว่าสำหรับแต่ละเส้นแนวนอน ซึ่งคือเส้น $y = k$ จะมี $x$ อยู่ไม่เกิน 2 ตัว ที่ทำให้ $y = |x - P[i]|$ ตัดกับเส้นดังกล่าว

จากนั้นเราจะจัดการลำดับที่เป็นคำตอบโดยการค่อย ๆ เพิ่มค่าเข้ามาในลำดับ โดยเริ่มต้นจะมีตัวเลขเพียงตัวในลำดับ นั่นคือ $i$ ที่เราเลือกมาตอนแรก ซึ่งหากอิงตามกราฟ $i$ คือจุดที่ $|x - P[i]|$ มีค่าเป็น $0$

ต่อจากนั้นเราจะค่อย ๆ ไล่ดู $k$ ตั้งแต่ $1, 2, 3, \ldots$ และพิจารณาทุก $j$ ที่ $d[i][j] = k$ โดยไอเดียในสำหรับแต่ละ $k$ คือ

- หากใน deque เก็บลำดับที่ประกอบด้วยทุก ๆ $j$ ที่ $d[i][j] < k$ แล้ว 
    - เราจะสามารถเติม $j$ ใหม่ ที่ $d[i][j] = k$ เข้าไปให้หมด เพื่อทำให้ deque ของเราเก็บลำดับที่ทุก ๆ $j$ ที่ $d[i][j] \leq k$ อยู่ใน deque ทั้งหมดได้

โดยกระบวนการจะแบ่งออกเป็น 2 ส่วน ได้แก่

### ส่วนที่ 1

หาก $k$ ปัจจุบันยังมี $j$ ถึง 2 ตัว ที่ $d[i][j] = k$ สังเกตว่าหนึ่งใน $j$ เหล่านั้นจะต้องมาต่อที่ข้างหน้าลำดับ ส่วนอีก $j$ จะต้องมาต่อที่ข้างหลัง

![2 Candidate Points](/media/cat/2points.png)
*ตัวอย่างกราฟสำหรับ $k=2$*

ในกรณีนี้ การจะหาว่า $j$ ใดควรไปอยู่ที่ใด เราจะต้องถามเป็นจำนวน 1 ครั้งอย่างหลีกเลี่ยงไม่ได้ แต่ก็แลกมากับการที่เราจะได้ตัวในลำดับเพิ่มขึ้นถึง 2 ตัว

### ส่วนที่ 2

หาก $k$ ปัจจุบันมี $j$ เพียง 1 ตัว ที่ $d[i][j] = k$ สังเกตว่านอกจาก $k$ ตัวแรกที่เข้าเงื่อนไขนี้ เราจะไม่จำเป็นต้องถามอีกเลยเนื่องจาก $j$ ที่ $d[i][j] = k$ จะต้องอยู่ติดกับ $j'$ ที่ $d[i][j'] = k-1$ เสมอ และหาก $j'$ ที่ $d[i][j'] = k-1$ มีเพียงตัวเดียว เราจะสามารถรู้ตำแหน่งของ $j$ ปัจจุบันได้เลยโดยไม่ต้องถาม

อีกทั้งหากมี $k$ ที่มี $j$ เพียงตัวเดียวแล้ว สำหรับ $k+1, k+2, \ldots$ ก็จะมี $j$ เพียงตัวเดียวเช่นกัน

### จำนวนครั้งที่ถาม

เราจะต้องถาม $N-1$ ครั้งในรอบแรก (เพราะไม่ต้องถาม $d[i][i]$) จากนั้นเราจะแยกการคำนวณเป็น 2 ส่วน คือ

1. ในส่วนที่ 1 การถาม 1 รอบจะได้ตัวในลำดับเพิ่มขึ้นมา 2 ตัว 
2. ในส่วนที่ 2 เราจะถามไม่เกิน 1 ครั้งตลอดการทำงานแน่นอน

หากคิดในกรณีแย่สุด เราจะต้องเสียการถาม 1 ครั้งให้กับส่วนที่ 2 ซึ่งทำในการถามรวมเป็น $N - 1 + 1 = N$

และสำหรับในส่วนที่ 1 สังเกตว่าเราจะต้องถามไม่เกิน $\lceil \frac{N}{4} \rceil$  รอบ เนื่องจากหากถามเป็นจำนวนนั้น จะทำให้เราได้ตัวในลำดับมา $\lceil \frac{N}{4} \rceil \times 2 = \lceil \frac{N}{2} \rceil$ ตัว ซึ่งมากพอตามที่โจทย์ต้องการพอดี

ทำให้เราจะต้องถามเป็นจำนวน $N + \lceil \frac{N}{4} \rceil$ รอบ นั่นเอง

## Implementation

```cpp
vector<int> select(int n) {
    vector<vector<int>> pos(n);
    for (int i = 1;i < n;i++) {
        pos[ask(0, i)].push_back(i);
    }
    if ((int)pos[1].size() == 1) { // P[0] = 1 or N
        vector<int> ans;
        ans.push_back(0);
        for (int j = 1;j < n;j++) {
            ans.push_back(pos[j][0]);
        }
        return ans;
    }
    deque<int> res;
    // order doesn't matter on first 2 elements
    res.push_back(pos[1][0]);
    res.push_back(0);
    res.push_back(pos[1][1]);
    int st = -1;
    for (int j = 2;j < n;j++) {
        if ((int)res.size() >= (n + 1) / 2) break;
        if ((int)pos[j].size() == 1) { // Phase 2
            if (st == -1) { // first element that has one j
                if (ask(res.back(), pos[j][0]) == 1) st = 1;
                else st = 0;
            }
            if (st) res.push_back(pos[j][0]);
            else res.push_front(pos[j][0]);
        }
        else { // Phase 1
            if (ask(res.back(), pos[j][0]) == 1) res.push_back(pos[j][0]), res.push_front(pos[j][1]);
            else res.push_back(pos[j][1]), res.push_front(pos[j][0]);
        }
    }
    // transform to vector 
    vector<int> ans;
    while (!res.empty()) ans.push_back(res.back()), res.pop_back();
    return ans;
}
```

Time Complexity : $O(N)$

Space Complexity : $O(N)$
