# Elephant (Communication)

ข้อนี้เป็นโจทย์ประเภท Communication ข้อแรกในประวัติศาสตร์ข้อสอบ TOI ซึ่งได้มีการประกาศล่วงหน้าว่าจะมีการเพิ่มโจทย์ประเภทนี้มาเป็นจำนวน *1* วันก่อนสอบ 

## โจทย์โดยย่อ

มีช้างอยู่ $N$ ตัว (เรียกว่าตัวที่ $0, 1, 2, \ldots, N-1$) โดยที่ช้างแต่ละตัวจะมีกลุ่มของมัน โดยเราจะต้องเขียนฟังก์ชันสองตัวได้แก่

- `long long encode(int N)`
    - ในฟังก์ชันนี้ เราสามารถเรียกฟังก์ชัน `bool same_group(int i,int j)` ซึ่งจะคืนค่า `true` ก็ต่อเมื่อ ช้างตัวที่ $i$ และช้างตัวที่ $j$ อยู่กลุ่มเดียวกัน โดยที่ฟังก์ชันดังกล่าวสามารถเรียกเป็นจำนวนกี่ครั้งก็ได้
    - เราจะต้องคืนค่าจำนวนเต็มที่ไม่เป็นลบ $K$ ที่มีค่าไม่เกิน $M$

- `vector<int> decode(int N, long long K)`
    - ในฟังก์ชันนี้ เราจะต้องคืนค่า $A$ ซึ่งเป็น `vector<int>` ขนาด $N$ จากค่า $K$ ที่ได้มาจาฟังก์ชัน `encode`
    - $A$ จะต้องทำให้เงื่อนไขต่อไปนี้เป็นจริง
        - $A[i] = A[j]$ ก็ต่อเมื่อช้างตัวที่ $i$ กับช้างตัวที่ $j$ อยู่กลุ่มเดียวกัน 

เพราะฉะนั้น สิ่งที่โจทย์ข้อนี้ให้เราทำจริง ๆ คือ

1. หาวิธีแปลงการจัดกลุ่มช้างทุก ๆ แบบเป็นเลขตัวเดียว คือ $K$ ซึ่งมีค่าไม่เกิน $M$
2. หาวิธีแปลงค่า $K$ กลับเป็นการจัดกลุ่มของช้าง

### ขอบเขตตัวแปร

- $1 \leq N \leq 20$
- $0 \leq M \leq 52 \times 10^{12}$


## ปัญหา

ในข้อนี้จะมีปัญหาที่เราจะต้องแก้ได้ให้ ดังนี้

1. เราจะต้อง map การจัดกลุ่มทุกแบบให้เป็นเลข $K$ **ที่แตกต่างกัน** ให้ได้ เพราะหากเรา map การจัดกลุ่มสองแบบเป็นค่า $K$ เดียวกัน ในส่วนตอนเรียกฟังก์ชัน `decode` เราจะไม่มีทางรู้เลยว่า $K$ ที่ได้รับมานั้น ควรจะ map ไปหาการจัดกลุ่มแบบไหน
2. เราจะต้องบีบ $K$ ให้มีค่าน้อย ๆ เพราะหากเรา map การจัดกลุ่มของช้างเป็นเลขที่มีค่ามากเกินไปจะทำให้เลข $K$ ที่ได้ออกมาเกินขอบเขตของโจทย์ (หรือก็คือ $K > M$ )


## Subtask 1, 4 ($K = N^{N-1}$) 

เราจะลองกำหนดหมายเลขของกลุ่มให้ช้างแต่ละตัวก่อน 

![Elephant1](/media/elephant/elephant1.png)

ซึ่งวิธีกำหนดหมายเลขคือเราจะทำกระบวนการต่อไปนี้ 

- กำหนด `idx` กลุ่มเริ่มต้นเป็น $0$
- กำหนดลำดับ `a` สำหรับเก็บหมายเลขกลุ่มของช้างแต่ละตัว
- เราจะค่อย ๆ ไล่จากช้างตัวที่ $0$ จนถึงตัวที่ $N-1$ โดยที่ในแต่ละตัว
    - ไล่ดูตัวก่อนหน้าทั้งหมด หรือก็คือสำหรับตัวที่ $i$ เราจะไล่ดูทุกตัวตั้งแต่ตัวที่ $0, 1, 2$ ไปเรื่อย ๆ จนถึงตัวที่ $i-1$ โดยเราจะแทนตัวที่เราพิจารณาเป็น $j$
    - กล่าวอีกแบบได้ว่าเราจะไล่ $j$ ตั้งแต่ $0, 1, 2, \ldots, i-1$
    - ทำการเรียก `same_group(i, j)`
        - หากไม่มี $j$ ใดเลยที่ให้ค่า `true` ให้ขึ้น $i$ เป็นกลุ่มใหม่ โดยเพิ่มค่า `idx` ขึ้น 1
        - หากพบ $j$ ที่ให้ค่า `true` ให้กำหนดหมายเลขกลุ่มของ $i$ ตาม หมายเลขกลุ่มของ $j$

โดยเราจำสามารถเขียนเป็นโค้ดภาษา C++ ได้ดังนี้

### Algorithm 1
```cpp
int idx = 0;
vector<int> a(n, 0); // a[0] = 0 
for (int i = 1;i < n;i++) { // start from 1
    bool ch = 0; // check if found same group or not
    for(int j = 0;j < i;j++){
        if(same_group(i, j)){
            a[i] = a[j];
            ch = 1;
            break;
        }
    }
    if(!ch){ // if not found
        a[i] = ++idx; // start new group index (idx+1)
    }
}
```

โดยถ้าเรากำหนดหมายเลขกลุ่มของช้างในตัวอย่างซึ่งแบ่งกลุ่มตามสี ด้วย Algorithm ข้างต้น เราจะได้หมายเลขช้างดังนี้

![Elephant2](/media/elephant/elephant2.png)

โดยเราจะสามารถสังเกตได้อีกว่า 

> จะมีจำนวนกลุ่มไม่เกิน $N$ กลุ่ม เสมอ

เนื่องจากจำนวนกลุ่มจะถูกจำกัดตามจำนวนช้าง

หรือก็คือ $0\leq a[i] < N$ สำหรับ $i = 0, 1, 2, \ldots, N-1$

ตามนิยาม เราเลยสามารถมอง $a$ เป็นเลขฐาน $N$ ได้ โดยที่ให้ $a[i]$ แทนเลขหลักที่ $i$ 

การแปลง $a$ ให้กลายเป็น $K$ เลยเปรียบเสมือนการแปลงเลขฐาน $N$ เป็นเลขฐาน $10$ 

ในทำนองเดียวกัน การแปลง $K$ กลับเป็น $a$ ก็จะเปรียบเสมือนการแปลงเลขฐาน $10$ กลับไปเป็นเลขฐาน $N$ นั่นเอง

โดยที่เลขฐาน $N$ ที่มี $N$ หลัก เมื่อแปลงเป็นเลขฐาน $10$ แล้วจะมีค่าสูงสุดเท่ากับ $N^N-1$

และข้อสังเกตอีกข้อที่เราสังเกตได้คือ

> $a[0] = 0$ เสมอ

นั่นทำให้เราลดหลักในเลขฐาน $N$ ของเราลงได้ 1 หลัก ทำให้ค่ามากสุดของ $K$ กลายเป็น $N^{N-1} - 1$ ซึ่งหากใช้วิธีนี้จะทำให้ได้คะแนนใน subtask 1, 4

## Subtask 5 ($N \leq 10, M = 10^5$)

สังเกตว่าสำหรับ Subtask นี้ จะมีค่า $N$ น้อยมาก ๆ  ซึ่งทำให้เราสามารถ brute force วิธีการแบ่งกลุ่มช้างทุกแบบที่เป็นไปได้ และ map การจัดกลุ่มทุกแบบไปเป็นค่า $K$ ได้เลย

โดยไอเดียคือเราจะจำลองการทำงาน [Algorithm 1](#algorithm-1) ทุกแบบที่เป็นไปได้ และเมื่อถึงช้างตัวที่ $N - 1$ เราจะหยุดและ map การจัดกลุ่มในกรณีนั้น ๆ ไปเป็นค่า $K$ ไล่จาก $0, 1, 2, \ldots,$ ไปจนถึง จำนวนวิธีทั้งหมดลบด้วย $1$

โดยการจำลองแบบนี้จะทำให้ $K$ มีค่าน้อยที่สุดเท่าที่เป็นไปได้สำหรับแต่ละ $N$ เลยนั่นเอง

การจำลองทำได้โดยใช้ Recursive Function โดยหากอิงตาม [Algorithm 1](#algorithm-1)  จะมี state ใน Recursive Function ทั้งหมด 2 states คือ 

1. `i` คือช้างตัวที่พิจารณาอยู่
2. `idx` คือจำนวนหมายเลขกลุ่ม **สูงสุด** ณ ปัจจุบัน


โดยสำหรับ $N = 4$ จะได้ Recursion Tree ดังรูป

![Recursion Tree 1](/media/elephant/recursiontree.png)

- เลขบนโหนดคือ `idx`
- เลขบนเส้นเชื่อมคือ `a[i+1]`
- level ของแต่ละโหนดคือ `i`

โดยเราจะไล่ map $K$ จาก $0, 1, 2, \ldots$ ตามลำดับ leaf จากซ้ายไปขวาตามลำดับ

ซึ่งสามารถเขียนเป็นโค้ดภาษา C++ ได้ดังนี้

### Algorithm 2
```cpp
vector<int> a(n, 0);
int k = 0;
void recur(int i,int idx){
    if(i == n-1){  // base case
        /*
            map (k) to (a) somehow
        */
        k++;
        return;
    }
    // same group
    for(int j=0;j<=idx;j++){
        a[i+1] = j;
        recur(i+1, idx);
    }
    // new group
    a[i+1] = idx+1;
    recur(i+1, idx+1)
}
...
// start from i = 0, idx = 0
recur(0, 0);
```

## Full Solution

สังเกตว่าหากเราสามารถจำลองการสร้าง Recursion Tree ได้ไว ๆ เราก็จะสามารถแปลง $a$ ไปเป็น $K$ และแปลง $K$ กลับมาหา $a$ ได้

### เดินบน Recursion Tree ให้ไวขึ้น

หากเราสามารถรู้จำนวนวิธีที่เกิดขึ้นได้จาก child ของแต่ละโหนด Recursion Tree เราก็ไม่จำเป็นต้องเรียก Recursive Function ลงไปจริง ๆ แต่เราสามารถใช้จำนวนวิธี (จำนวน leaf) ใน subtree ของ child ตัวนั้น ๆ ในการประกอบการคำนวณค่า $K$ ได้เลย ทำให้สามารถแปลง $a$ เป็น $K$ ได้ภายในเวลา $O(N)$ หรือ $O(N^2)$ 

![Walk On Tree](/media/elephant/walkonrecurtree.gif)

เรายังสามารถใช้วิธีที่คล้าย ๆ กันในการแปลง $K$ กลับไปยัง $a$ ได้อีกด้วย

![Walk On Tree](/media/elephant/walkonrecurtree2.gif)

### Dynamic Programming

ปัญหาการคำนวณจำนวนวิธี หากไม่นับวิธีการคำนวณตรง ๆ โดยใช้ Closed Form เราก็จะต้องใช้วิธีอย่าง Dynamic Programming มาคำนวณจำนวน leaf (จำนวนวิธี) บน Subtree ของ Recursion Tree นั่นเอง

โดยเราจะนิยาม $dp[pos][x]$ เป็นจำนวนวิธีในการแบ่งกลุ่มหากเริ่มต้นที่ $i = pos$ และ $idx = x$ หรือก็คือจำนวนวิธีใน Subtree (pos, x) บน Recursion Tree 

โดยเราจะสามารถเขียนสมการ $dp$ ได้ดังนี้

Base Case
- $dp[N-1][j] = 1$ สำหรับ $j = 0, 1, 2, \ldots, N-1$ 

Recurrence 
- $dp[i][j] = (j+1) \times dp[i+1][j] + dp[i+1][j+1]$ 
- สำหรับ $i = 0, 1, 2, \ldots, N-2$

ซึ่งในส่วนของ Recurrence เราจะมอง $(i, j)$ เป็นโหนดบน Recursion Tree ที่มี children ไล่จากซ้าบไปขวา ได้แก่

- $(i+1,j)$ จำนวน $j+1$ โหนด
- $(i+1,j+1)$ จำนวน $1$ โหนด

โดยเราจะใช้ข้อมูลเหล่านี้ในการ map ค่า $K$ เข้ากับลำดับ $a$

### แปลง $a$ เป็น $K$

หลังจากคำนวณ $a$ และ $dp$ แล้ว เราจะไล่ตั้งแต่ $i = 0, 1, 2, \ldots, N-2$ โดยสำหรับแต่ละ $(i, j)$ เราจะแบ่งการเดินเป็น 2 กรณี ได้แก่

1. เดินไป $(i+1,j)$ ซึ่งคือกรณีที่ `idx` มีค่าเท่าเดิม ตาม [Algorithm 1](#algorithm-1)
2. เดินไป $(i+1,j+1)$ ซึ่งคือกรณีที่ `idx` มีค่าเพิ่มขึ้น 1 ตาม [Algorithm 1](#algorithm-1)

โดยการคำนวณค่า $K$ ที่เพิ่มขึ้นมาในแต่ละ $i$ จะเท่ากับ $$a[i+1] \times dp[i+1][j]$$

![Walk On Tree](/media/elephant/walkonrecurtree.gif)


### แปลง $K$ กลับเป็น $a$

หลังจากคำนวณ $dp$ แล้ว เราจะไล่ตั้งแต่ $i = 0, 1, 2, \ldots, N-2$ โดยสำหรับแต่ละ $i$ เราจะแบ่งการเดินเป็น 2 กรณี ได้แก่

1. เดินไป $(i+1,j)$ ซึ่งคือกรณีที่ `idx` มีค่าเท่าเดิม ตาม [Algorithm 1](#algorithm-1)
2. เดินไป $(i+1,j+1)$ ซึ่งคือกรณีที่ `idx` มีค่าเพิ่มขึ้น 1 ตาม [Algorithm 1](#algorithm-1)

สำหรับแต่ละ $i$ เราจะใช้ค่า $K$ ในการตัดสินใจว่าค่า $a$ ตัวถัดไปจะอยู่ในกรณีใด อิงจากสูตรการคำนวณค่า $K$ สำหรับแต่ละ $i$

1. หาก $K < (j+1) \times dp[i+1][j]$ หมายความว่าจะไม่มีการขึ้น `idx` ใหม่ใน $a[i+1]$ อย่างแน่นอน 
2. ไม่เช่นนั้น จะได้ว่ามีการขึ้น `idx` ใหม่บน $a[i+1]$

![Walk On Tree](/media/elephant/walkonrecurtree2.gif)

โดยในการ Implement จริง เราจะดักกรณีที่ 2 ไว้ก่อน หรือก็คือตรวจสอบว่า $K \geq (j+1) \times dp[i+1][j]$ หรือไม่ก่อน แล้วจึงค่อยไปหา $a[i+1]$ สำหรับกรณีที่ 1

## Implementation

### Encode :

```cpp
long long encode(int N) {
    int n = N;
    vector<vector<long long>> dp(n + 1, vector<long long>(n + 1, 0ll));
    for (int i = 0;i < n;i++) {
        dp[n - 1][i] = 1;
    }
    for (int i = n - 2;i >= 0;i--) {
        for (int j = 0;j <= i;j++) {
            dp[i][j] = dp[i + 1][j] * (j + 1) + dp[i + 1][j + 1];
        }
    }
    long long K = 0;
    int idx = 0;
    vector<int> a(n, 0);
    for (int i = 1;i < n;i++) {
        bool ch = 0;
        for (int j = 0;j < i;j++) {
            if (same_group(i, j)) {
                a[i] = a[j];
                ch = 1;
                K += dp[i][idx] * a[i];
                break;
            }
        }
        if (!ch) {
            a[i] = idx + 1;
            K += dp[i][idx] * a[i];
            idx++;
        }
    }
    return K;
}
```

Time Complexity : $O(N^2)$

Space Complexity : $O(N^2)$


### Decode :

```cpp
vector<int> decode(int N, long long K) {
    int n = N;
    vector<vector<long long>> dp(n + 1, vector<long long>(n + 1, 0ll));
    for (int i = 0;i < n;i++) {
        dp[n - 1][i] = 1;
    }
    for (int i = n - 2;i >= 0;i--) {
        for (int j = 0;j <= i;j++) {
            dp[i][j] = dp[i + 1][j] * (j + 1) + dp[i + 1][j + 1];
        }
    }
    vector<int> a(n, 0);
    int idx = 0;
    for (int i = 0;i < n - 1;i++) {
        if (K >= (idx + 1) * dp[i + 1][idx]) {
            K -= (idx + 1) * dp[i + 1][idx];
            a[i + 1] = ++idx;
        }
        else {
            while (K >= dp[i + 1][idx]) {
                K -= dp[i + 1][idx];
                a[i + 1]++;
            }
        }
    }
    return a;
}
```

Time Complexity : $O(N^2)$

Space Complexity : $O(N^2)$
